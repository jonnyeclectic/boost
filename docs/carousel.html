zsh — boost install
Package Management

boost install

Install a skill from a tap registry

One command copies a skill into the canonical store, symlinks it into every agent you've got enabled — Claude Code, Windsurf, Cursor — and records it in the lock file with a quality score attached. No hand-copying SKILL.md into three different folders.

uninstallsyncupdatebundle importpinsnapshotexport

zsh — boost search
Discovery & Search

boost search

Search skills across tap registries (AI-ranked)

Search isn't grep over filenames — it's full-content BM25 over every skill's body text, so a query can match a rule buried three headings deep with no setup required. Ranked results ship with a relevance meter, and --smart reranks the top hits with Claude when it's available.

reindexdiscoverrecommendbrowse trendingstatscount

zsh — boost explain
Skill Information

boost explain

Explain what a skill does in plain English

Point it at any skill in a tapped registry — installed or not — and get a plain-English read of what it changes about the agent's behavior and when it triggers. With no claude CLI or API key on hand it falls back to an honest heuristic: description, outline, and every always/never rule.

listinfocatpreview logdepstag

zsh — boost tap
Registry (Taps)

boost tap

Add a GitHub repo as a skill registry

Tap any bare GitHub repo — or browse the bundled catalog of 100+ classified registries offline with --catalog --dry-run before committing to one. Once tapped, everything inside becomes searchable and installable.

untaptapsoutdated

zsh — boost distill
Intelligence

boost distill

Merge multiple skills into one deduplicated skill

Distill folds two or more skills into a single SKILL.md — union the tags, keep every distinct rule once, drop the redundant ones — with Claude doing the merge when it's available and a mechanical, honest fallback when it isn't.

simulateinferabsorbevolve contextfocusimpact

zsh — boost doctor
Quality & Health

boost doctor

Check installation health & report issues

Doctor audits git, every tap, the lock file, each installed skill's agent symlinks, and log rotation in one pass — then names the exact command that fixes whatever it finds. Here it catches a skill wiped from the store, and heal restores it straight from the tap.

lintauditverifydrift healconflictattesthealth

Manage Claude Code hooks (scope-aware) in settings.json

Add, list, and remove Claude Code hooks at either scope without hand-editing JSON. Every hook boost creates is tagged with a marker comment, so it only ever touches hooks it made — yours are always left alone.
